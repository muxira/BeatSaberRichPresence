1. Description of the Mod

The Mod is a free, open-source plugin for Beat Saber that displays your in-game activity (such as song name, difficulty, combo, energy, and match results) as a Discord Rich Presence status. The Mod communicates with the Discord desktop client running on your local machine via the DiscordCore library.
